# YouTube Niche Research

`YouTube_Niche_Research.xlsx` — niche-finding tracker for a faceless, AI-produced
YouTube channel (US audience, $20-70/video budget, freelance editing).

Data pulled 2026-08-02 from Nexlev's live YouTube channel database. Covers 10
candidate niches / 110 unique channels, screened against: sub-100k subscribers,
launched in the last 6 months, proven virality (500k+ view videos, 100k+
baseline), and budget/length fit.

Sheets:
- **Read Me** — methodology, screening criteria, caveats
- **Channel Tracker** — raw data on all 110 tracked channels
- **Niche Summary** — the 10 niches, aggregated (live formulas off the tracker)
- **Top Niche Picks** — the 5 recommended niches with rationale
- **Competitor Lists** — 10-15 named competitors per recommended niche

Free-tier API quota limited this pass to 10 niche queries — re-run
`search_niche_finder_channels` for more candidate topics (tech, ASMR, finance,
additional sports/true-crime sub-formats) to widen the funnel further.
